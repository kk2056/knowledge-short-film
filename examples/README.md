# 示例

两段**自己题目的样片**（`fold_C`、`pigeon_B`，两套外观各一段），一张货架图，一段引擎件演示。

这里的东西是"别人怎么做过一次"，不是零件库。文案不同，屏上的东西就不同，代码也不同：新片的每一镜按自己的分镜表现写，不要把这里的珠子、细胞、数轴、骰子搬过去。能带走的是做法（一张分镜表怎么变成画面、哪些东西画在底层、推拉镜头怎么插值、怎么截图自查），不是画面。

`fold_C/`：《折叠》的开头（序 + 第一章），C 夜曲，33 秒，九镜。讲的是血红蛋白错一颗氨基酸怎么把红细胞变成镰刀。
先写的分镜表（`storyboard.md`），再照着做的 `film.js`；`gen_blob.py` 算出"折好的一团"里每颗珠子的位置（`layout.js`）。
可以看的做法：一个世界一台摄影机（血管 → 细胞 → 一串珠子，对数缩放的推拉）；有体积的红细胞画在底层不吃辉光；有光泽的珠子；
珠串卷成一团；一团的凹口卡住另一团鼓出来的珠子；细胞里的小球排成杆把细胞顶弯；提问和结论那两镜什么都不加。
`fold_old_vs_new.jpg` 是同一段内容的两版对照：上排是这个 skill 早先做的（主体是一串星点连成的折线），下排是重做的。为什么差这么多，见 `references/visualization.md` 第〇节和第七节。

`pigeon_B/`：《鸽子的迷信》的开头，B 寓言，33 秒，七句字幕、六个镜头。讲的是斯金纳 1948 年的实验。
这 33 秒只讲一件事：食物按时间来，可它掉下来时鸽子碰巧在转圈，于是鸽子接着转。规则卡、八只鸽子、幸运袜都留给后面——塞进来反而抽象。
可以看的做法：计时器按真实时间走两圈（第 15、30 秒各掉一次食物）；鸽子这 30 秒在干什么写成一张关键帧表；
六个镜头六种景别（全景、特写、中景、近景、慢推、前后景）；两段没有字幕的纯画面；字幕底下压一层暗色，近景时东西不抢字。

```bash
python ../engine/render.py fold_C --sheet 16      # 拼图

```
